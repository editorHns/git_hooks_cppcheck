# Отчёт по заданию «Система контроля версий. Автоматизация действий»

## 1. Цель работы

Изучить механизм Git hooks и автоматизировать действия, выполняемые до и
после фиксации изменений.

## 2. Используемые инструменты

- Git;
- Bash;
- C++;
- cppcheck.

## 3. Реализованные hooks

Созданы два hook-скрипта.

### 3.1. pre-commit

Файл:

```text
.git/hooks/pre-commit
```

Перед созданием commit он выполняет:

```bash
git log -3 --oneline --decorate
```

и выводит краткую информацию о последних трёх commit.

### 3.2. post-commit

Файл:

```text
.git/hooks/post-commit
```

После создания commit запускает статический анализ:

```bash
cppcheck --enable=warning,style,performance,portability --error-exitcode=1 src
```

Таким образом, после фиксации изменений автоматически выполняется проверка
исходного кода.

## 4. Почему hooks хранятся в scripts

Git не отслеживает содержимое `.git/hooks` как обычные файлы проекта.
Поэтому исходники hooks помещены в:

```text
scripts/
```

а скрипт:

```text
scripts/install_hooks.sh
```

копирует их в `.git/hooks`.

## 5. Проверка pre-commit

Команда:

```bash
git commit -m "Initial commit"
```

вызывает pre-commit.

Пример вывода:

```text
=== PRE-COMMIT ===
Последние три изменения:
...
==================
```

Пример:

## 7. Проверка git log

Для самостоятельной проверки используется:

```bash
git log -3 --oneline --decorate
```

Команда показывает последние три commit.

## 8. Проверка статического анализа

Для ручного запуска:

```bash
cppcheck --enable=warning,style,performance,portability src
```

Для проверки с кодом возврата:

```bash
cppcheck --enable=warning,style,performance,portability --error-exitcode=1 src
```

## 9. Вывод

В работе был реализован механизм автоматизации Git с помощью hooks.
До создания commit запускается `pre-commit`, который показывает последние
три изменения. После создания commit запускается `post-commit`, выполняющий
статический анализ C++ проекта с помощью cppcheck.

Для переносимости проекта исходники hooks хранятся в репозитории отдельно,
а установка в `.git/hooks` выполняется специальным скриптом.
